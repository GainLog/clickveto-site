Privacy Policy

ClickVeto is designed as a local-first browser protection extension. This policy explains what data ClickVeto processes, what remains on your device, and the limited cases in which data is sent to an external service.

Last updated: 28 August 2026

Short version

Browsing protection decisions, settings and protection logs are processed locally in Chrome. ClickVeto does not sell browsing data and does not use it for advertising or profiling. Only Pro license activation and validation communicates with Lemon Squeezy's license service.

1. Controller / contact

ClickVeto is operated as the ClickVeto project by GainLog. Questions about privacy or the extension can be submitted through the ClickVeto support channel:

ClickVeto Support on GitHub

2. Single purpose of the extension

ClickVeto's single purpose is to protect users from unwanted browser actions and intrusive web behavior, including unwanted popups and popunders, suspicious redirects and tab swaps, risky downloads, unwanted advertising/network requests, deceptive overlays and related browser side effects.

3. Data processed locally

To provide that protection, ClickVeto may process the following data locally in the browser:

  • Web history / navigation context: website URLs, hostnames, top-level navigation events, redirect chains and source/target relationships needed to decide whether an action is expected or suspicious.
  • User activity: interaction context such as clicks, keyboard submit actions and the relationship between a user gesture and browser actions it triggers.
  • Website content and page metadata: limited DOM information, links, form targets, iframe attributes, overlay/ad markers and similar page signals needed to identify intrusive elements or distinguish intended actions from unwanted ones.
  • Protection configuration: settings, allowlists, blocklists, temporary exceptions, per-site rules, manually blocked elements, protection level and related preferences.
  • Local protection history: protection events, counters, download decisions, website reputation/adaptive signals and diagnostic information exposed by ClickVeto.

This information is used for browser protection and troubleshooting and is stored locally using Chrome extension storage unless otherwise stated below.

4. Data sent to Lemon Squeezy for Pro licensing

Core protection does not require a ClickVeto account or ClickVeto server. If you activate ClickVeto Pro with a license key, ClickVeto communicates directly over HTTPS with Lemon Squeezy's licensing API.

The extension may send:

  • the license key entered by the user;
  • a locally generated installation identifier, used as part of the license instance name;
  • the Lemon Squeezy license instance identifier when validating or deactivating an existing activation.

The licensing response may contain license, instance, customer and order identifiers. ClickVeto may keep license entitlement metadata locally so that Pro status can be displayed and periodically revalidated.

Payment information: purchases are completed on Lemon Squeezy's checkout. ClickVeto does not receive or store credit-card numbers, bank details, PayPal credentials or other payment-instrument data.

5. Data not sent to ClickVeto

  • ClickVeto does not upload your browsing history to a ClickVeto server.
  • ClickVeto does not transmit the contents of downloaded files to a ClickVeto server.
  • ClickVeto does not sell personal data or browsing data.
  • ClickVeto does not use browsing data for advertising, cross-site profiling, credit scoring or lending decisions.

6. Permissions and broad website access

ClickVeto requests access to websites you visit because its protection must work across arbitrary sites. That access is used to inspect only the navigation, interaction and page signals required for the disclosed protection features. Broad host access does not mean that browsing data is sent to ClickVeto.

7. Manually blocked elements

If you use “ClickVeto: Block element” from the context menu, ClickVeto creates a local site-specific rule so the selected element can remain hidden on later visits. These rules remain in local extension storage until they are removed, reset or the extension is uninstalled.

8. Backups

If you create a ClickVeto backup, the backup is generated locally and downloaded as a file chosen by you. Pro license data, the local license installation identifier and temporary/session permissions are excluded from ClickVeto backups.

9. Retention and deletion

Local settings and logs remain in the browser until they are cleared through ClickVeto, Chrome extension storage is removed, or ClickVeto is uninstalled. License entitlement data remains locally until deactivation, reset or uninstall, subject to revalidation with the license provider.

Support messages submitted through GitHub are handled by GitHub and remain subject to GitHub's own retention and privacy practices.

10. Website hosting

The ClickVeto website is hosted using GitHub Pages. When you visit the website, GitHub may process technical request data such as IP address, browser information and server logs according to GitHub's own privacy policy. ClickVeto does not add its own analytics or advertising trackers to this privacy page.

11. Security

License communication uses HTTPS. ClickVeto limits external data transfer to the licensing functions described above and keeps protection processing local wherever possible. No software can guarantee absolute security.

12. Chrome Web Store Limited Use

ClickVeto's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

User data is used only to provide or improve ClickVeto's disclosed browser-protection and license-entitlement functionality. It is not sold, used for personalized advertising, used to determine creditworthiness, or transferred for purposes unrelated to ClickVeto's single purpose.

13. Third-party services

  • Lemon Squeezy: checkout and Pro license activation/validation.
  • GitHub / GitHub Pages: website hosting and optional support through GitHub Issues.
  • Google Chrome / Chrome Web Store: browser platform and extension distribution. Chrome itself may process browser/extension information under Google's own terms and privacy policy.

14. Your choices and rights

You can disable ClickVeto, clear its local configuration, remove manually blocked elements, deactivate Pro, or uninstall the extension at any time. Depending on applicable law, you may also have rights relating to access, correction, deletion, restriction or objection regarding personal data processed by an external service. Requests concerning ClickVeto can be made through the support channel above; requests concerning Lemon Squeezy, GitHub or Google should also be directed to the relevant provider where appropriate.

15. Changes to this policy

This policy may be updated when ClickVeto's functionality, permissions or external service use changes. The “Last updated” date above identifies the current version.

Datenschutzerklärung

ClickVeto ist als lokal arbeitende Browser-Schutz-Erweiterung konzipiert. Diese Datenschutzerklärung beschreibt, welche Daten ClickVeto verarbeitet, was auf deinem Gerät bleibt und in welchen wenigen Fällen Daten an einen externen Dienst übertragen werden.

Kurzfassung

Schutzentscheidungen, Einstellungen und Schutzprotokolle werden lokal in Chrome verarbeitet. ClickVeto verkauft keine Browserdaten und nutzt sie weder für Werbung noch für Profilbildung. Nur die Aktivierung und regelmäßige Prüfung einer Pro-Lizenz kommuniziert mit dem Lizenzdienst von Lemon Squeezy.

1. Verantwortlicher / Kontakt

ClickVeto wird als ClickVeto-Projekt von GainLog betrieben. Fragen zum Datenschutz oder zur Erweiterung können über den ClickVeto-Support gestellt werden:

ClickVeto-Support auf GitHub

2. Alleiniger Zweck der Erweiterung

Der alleinige Zweck von ClickVeto ist der Schutz vor unerwünschten Browser-Aktionen und aufdringlichem Web-Verhalten, insbesondere unerwünschten Popups/Popundern, verdächtigen Redirects und Tab-Wechseln, riskanten Downloads, unerwünschten Werbe- und Netzwerkanfragen, täuschenden Overlays sowie damit verbundenen Browser-Nebenwirkungen.

3. Lokal verarbeitete Daten

Für diesen Schutz kann ClickVeto folgende Daten lokal im Browser verarbeiten:

  • Webprotokoll / Navigationskontext: Website-URLs, Hostnamen, Top-Level-Navigationen, Redirect-Ketten sowie Quell-/Zielbeziehungen, soweit dies für die Schutzentscheidung erforderlich ist.
  • Nutzeraktivität: Interaktionskontext wie Klicks, Tastatur-Auslösungen von Formularen und die Beziehung zwischen einer Nutzeraktion und den dadurch ausgelösten Browser-Aktionen.
  • Website-Inhalte und Seitenmetadaten: begrenzte DOM-Informationen, Links, Formularziele, iframe-Attribute, Werbe-/Overlay-Marker und vergleichbare Signale, die zur Erkennung störender Elemente oder zur Unterscheidung gewünschter und unerwünschter Aktionen nötig sind.
  • Schutzkonfiguration: Einstellungen, Allow-/Blocklisten, temporäre Freigaben, Website-Regeln, manuell blockierte Elemente, Schutzstufe und weitere Präferenzen.
  • Lokaler Schutzverlauf: Schutzereignisse, Zähler, Download-Entscheidungen, Website-Reputation/adaptive Signale sowie von ClickVeto bereitgestellte Diagnoseinformationen.

Diese Daten werden für Browserschutz und Fehlerdiagnose genutzt und – soweit nachfolgend nichts anderes genannt ist – im lokalen Chrome-Erweiterungsspeicher verarbeitet.

4. Datenübertragung an Lemon Squeezy für Pro-Lizenzen

Für den Kernschutz sind weder ein ClickVeto-Konto noch ein ClickVeto-Server erforderlich. Wenn du ClickVeto Pro mit einem Lizenzschlüssel aktivierst, kommuniziert ClickVeto direkt per HTTPS mit der Lizenz-API von Lemon Squeezy.

Dabei kann die Erweiterung insbesondere übermitteln:

  • den vom Nutzer eingegebenen Lizenzschlüssel;
  • eine lokal erzeugte Installationskennung, die als Bestandteil des Lizenz-Instanznamens verwendet wird;
  • die von Lemon Squeezy vergebene Instanz-ID bei späteren Validierungen oder einer Deaktivierung.

Die Antwort des Lizenzdienstes kann Lizenz-, Instanz-, Kunden- und Bestellkennungen enthalten. ClickVeto kann Lizenz-/Berechtigungsmetadaten lokal speichern, damit der Pro-Status angezeigt und regelmäßig erneut geprüft werden kann.

Zahlungsdaten: Der Kauf wird vollständig über den Checkout von Lemon Squeezy abgewickelt. ClickVeto erhält und speichert keine Kreditkartennummern, Bankdaten, PayPal-Zugangsdaten oder sonstige Zahlungsinstrumentdaten.

5. Daten, die ClickVeto nicht überträgt

  • ClickVeto lädt deinen Browserverlauf nicht auf einen ClickVeto-Server hoch.
  • ClickVeto überträgt den Inhalt heruntergeladener Dateien nicht an einen ClickVeto-Server.
  • ClickVeto verkauft keine personenbezogenen Daten oder Browserdaten.
  • ClickVeto nutzt Browserdaten nicht für Werbung, Cross-Site-Profilbildung, Bonitätsprüfung oder Kreditentscheidungen.

6. Berechtigungen und Zugriff auf Websites

ClickVeto benötigt Zugriff auf Websites, weil der Schutz auf beliebigen vom Nutzer besuchten Seiten funktionieren muss. Der Zugriff wird nur genutzt, um die für die beschriebenen Schutzfunktionen erforderlichen Navigations-, Interaktions- und Seitensignale auszuwerten. Eine breite Hostberechtigung bedeutet nicht, dass der Browserverlauf an ClickVeto übertragen wird.

7. Manuell blockierte Elemente

Wenn du über das Kontextmenü „ClickVeto: Element blockieren“ verwendest, legt ClickVeto eine lokale, websitespezifische Regel an, damit das ausgewählte Element bei späteren Besuchen ausgeblendet bleibt. Diese Regeln bleiben im lokalen Erweiterungsspeicher, bis sie entfernt/zurückgesetzt werden oder ClickVeto deinstalliert wird.

8. Backups

Ein ClickVeto-Backup wird lokal erzeugt und als Datei auf deinem Gerät gespeichert. Pro-Lizenzdaten, die lokale Lizenz-Installationskennung und temporäre bzw. sitzungsbezogene Freigaben werden nicht in ClickVeto-Backups exportiert.

9. Speicherdauer und Löschung

Lokale Einstellungen und Protokolle bleiben im Browser, bis sie über ClickVeto gelöscht/zurückgesetzt werden, der Erweiterungsspeicher entfernt wird oder ClickVeto deinstalliert wird. Lizenz-/Berechtigungsdaten bleiben bis zur Deaktivierung, zum Zurücksetzen oder zur Deinstallation lokal gespeichert und können regelmäßig beim Lizenzanbieter validiert werden.

Support-Nachrichten, die über GitHub eingereicht werden, werden von GitHub verarbeitet und unterliegen den dortigen Speicher- und Datenschutzregeln.

10. Hosting der Website

Die ClickVeto-Website wird über GitHub Pages bereitgestellt. Beim Aufruf kann GitHub technische Verbindungsdaten wie IP-Adresse, Browserinformationen und Server-Logs nach der eigenen Datenschutzerklärung verarbeiten. ClickVeto bindet auf dieser Datenschutzseite keine eigenen Analyse- oder Werbetracker ein.

11. Sicherheit

Die Lizenzkommunikation erfolgt über HTTPS. ClickVeto beschränkt externe Datenübertragungen auf die oben beschriebenen Lizenzfunktionen und verarbeitet Schutzdaten soweit wie möglich lokal. Eine absolute Sicherheit kann technisch nicht garantiert werden.

12. Chrome Web Store – Limited Use

Die Nutzung von Nutzerdaten durch ClickVeto entspricht der Chrome Web Store User Data Policy einschließlich der dortigen Limited-Use-Anforderungen.

Nutzerdaten werden nur verwendet, um die offengelegten Browserschutz- und Lizenzberechtigungsfunktionen bereitzustellen bzw. zu verbessern. Sie werden nicht verkauft, nicht für personalisierte Werbung oder Bonitätsentscheidungen genutzt und nicht für Zwecke übertragen, die nichts mit dem alleinigen Zweck von ClickVeto zu tun haben.

13. Eingesetzte Drittanbieter

  • Lemon Squeezy: Checkout sowie Aktivierung/Validierung von Pro-Lizenzen.
  • GitHub / GitHub Pages: Hosting der Website und optionaler Support über GitHub Issues.
  • Google Chrome / Chrome Web Store: Browserplattform und Verteilung der Erweiterung. Chrome selbst kann Browser-/Erweiterungsinformationen nach den eigenen Bedingungen und Datenschutzregeln verarbeiten.

14. Wahlmöglichkeiten und Betroffenenrechte

Du kannst ClickVeto jederzeit deaktivieren, die lokale Konfiguration löschen, manuell blockierte Elemente entfernen, Pro deaktivieren oder die Erweiterung deinstallieren. Je nach anwendbarem Recht können zusätzlich Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung oder Widerspruch bezüglich personenbezogener Daten bestehen. Anfragen zu ClickVeto können über den oben genannten Support-Kanal gestellt werden; Anfragen zu Lemon Squeezy, GitHub oder Google sollten – soweit einschlägig – zusätzlich direkt an den jeweiligen Anbieter gerichtet werden.

Diese Datenschutzerklärung kann angepasst werden, wenn sich Funktionen, Berechtigungen oder die Nutzung externer Dienste von ClickVeto ändern. Maßgeblich ist das oben angegebene Aktualisierungsdatum.
