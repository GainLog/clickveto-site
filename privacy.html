Privacy Policy

ClickVeto is designed as a local-first browser protection extension. This policy explains what data ClickVeto processes, what remains on your device, and the limited cases in which data is sent to an external service.

Last updated: 30 October 2026

Short version

Browsing protection decisions, settings and protection logs are processed locally in Chrome. ClickVeto does not sell browsing data and does not use it for advertising or profiling. Only Pro license activation, validation and deactivation communicate with Polar's license service.

1. Controller / contact

ClickVeto is operated as the ClickVeto project by GainLog. Questions about privacy or the extension can be submitted through the ClickVeto support channel:

ClickVeto Support on GitHub

2. Single purpose of the extension

ClickVeto's single purpose is to protect users from unwanted browser actions and intrusive web behavior, including unwanted popups and popunders, suspicious redirects and tab swaps, risky downloads, unwanted advertising/network requests, deceptive overlays and related browser side effects.

3. Data processed locally

To provide that protection, ClickVeto may process the following data locally in the browser:

  • Web history / navigation context: website URLs, hostnames, top-level navigation events, redirect chains and source/target relationships needed to decide whether an action is expected or suspicious.
  • User activity: interaction context such as clicks, keyboard submit actions and the relationship between a user gesture and browser actions it triggers.
  • Website content and page metadata: limited DOM information, links, form targets, iframe attributes, overlay/ad markers and similar page signals needed to identify intrusive elements or distinguish intended actions from unwanted ones.
  • Protection configuration: settings, allowlists, blocklists, temporary exceptions, per-site rules, manually blocked elements, protection level and related preferences.
  • Local protection history: protection events, counters, download decisions, website reputation/adaptive signals and diagnostic information exposed by ClickVeto.

This information is used for browser protection and troubleshooting and is stored locally using Chrome extension storage unless otherwise stated below.

3a. Optional local measurement

Optional measurement counters are disabled by default. After you enable them, they count activity days, Pro hints, Pro-page views, purchase-button clicks, opened checkout tabs and license activations. They contain no URLs, website names, license keys or user identifiers and are not transmitted. Disabling measurement deletes counter data. They describe this browser only; opening checkout does not prove a purchase. Hint limits and snoozing work independently of measurement consent.

3b. Personal element rules

Personal element rules contain the website domain, a DOM selector, a rule ID and creation time. They are stored locally, without page text or complete URLs, and are not transmitted.

3c. Player tools and website profiles

Clear player temporarily hides recognized transparent click traps. Original display properties remain only in page memory for Undo; no saved element rule is created. Tame website stores the exact website domain, enabled state and creation time locally (up to 300 profiles), without full URLs or page contents. These new data are not transmitted or synchronized. Profiles persist after reload, are included in exported backups and can be removed in My hidden elements even in Free. Profiles do not apply while protection is off, the website is excepted or Pro is unavailable. Existing local protection logs may still contain URLs as described above.

3d. Provisional windows in Lockdown

To check an initially blank window, ClickVeto temporarily stores the source domain, an explicitly allowed destination domain when applicable, browser tab IDs and creation time in local Chrome session storage (up to 64 records). These data are not synchronized, transmitted or included in settings backups. The record is removed after the first completed destination is checked or the window is closed; session storage is cleared when the browser exits. Blocks can record the target URL and reason in the existing local protection log. Closing a foreign destination does not guarantee preventing its initial network request.

3e. Automatic cosmetic ad filtering (Pro)

Pro uses cosmetic CSS rules bundled from EasyList and EasyList Germany. No cosmetic list downloads occur at runtime and no page contents, URLs or filter-match counts are sent to the list authors or ClickVeto. The enabled setting and up to 300 exact website domains paused by you are stored locally and included in settings backups. Styles and current-page match counts remain in page memory. Pausing cleanup, turning protection off, a website exception or losing Pro access removes this feature’s styles without deleting page elements. These new settings are local only; existing network-filter downloads are described in section 13a.

3f. Optional comfort mode and cookie rejection (Pro)

Comfort mode is off by default. To recognize supported newsletter/survey popups and muted floating autoplay videos, ClickVeto examines DOM markers, limited local element text, form/media attributes and interaction state in the page. This processing remains in page memory; content and match counts are not transmitted or stored as a history. Temporary hidden-element and scroll properties are kept in page memory for restoration. Global choices and up to 300 exact-domain comfort profiles (category flags, activation state, creation time, pause/resume state and ownership marker for an optionally created taming profile) remain local and are included in settings backups. Removing a profile restores only a taming profile created by this tool when its creation marker still matches. Cookie rejection is a separate explicit opt-in, independent of nuisance hiding, global or per website, and may be restored from an imported settings backup. It clicks visible known reject/necessary controls in supported consent dialogs, at most five attempts per page. It does not click accept-all, manually alter consent cookies, or hide unsupported cookie requests. Websites or their consent providers may store or receive that rejection through their normal consent processing and network requests. Their privacy notices apply. Turning the feature off stops future actions; it cannot undo a submitted choice or prove all tracking stopped.

3g. Optional local captcha assistance (Pro, experimental)

This section describes the experimental local 1.0.37 candidate, which is not yet included in the published Store version. It applies only if you use that candidate and explicitly enable the assistance.

This feature is off by default and requires explicit enablement for individual website domains. Bundled OCR and image-classification models process captcha images, limited prompt text and relevant form/checkbox state locally. Images, recognized text and predictions are kept in memory only and are not sent to ClickVeto, model authors or a paid solving service. If an image cannot be read from the page, its original website or captcha-provider image URL may be fetched without cookies or a referrer; that original host receives ordinary connection data including the IP address. No captcha-solving API, model download or remote inference is used at runtime. Models and English character-recognition data ship in the package. The enabled flag and up to 300 exact-domain choices are saved locally and excluded from settings backups. One current outcome code and timestamp per tab may be kept in memory for this browser session, without images or full URLs. Supported results may fill an empty captcha field or select image tiles; ClickVeto does not itself submit the surrounding form. A visible provider confirmation checkbox may be attempted once per page, which can trigger the provider's normal verification traffic. Provider server checks and acceptance are not bypassed or guaranteed. Uncertain tasks stay manual. Turning the feature off, protection off, website exceptions or loss of Pro stop future processing; in-flight results are checked again before use. A temporary offscreen document runs local workers and releases models after idle time. No paid service or extra account is required.

4. Data sent to Polar for Pro licensing

Core protection does not require a ClickVeto account or ClickVeto server. If you activate, validate or deactivate ClickVeto Pro, ClickVeto communicates directly over HTTPS with Polar's licensing API.

The extension may send:

  • the license key entered by the user;
  • the ClickVeto Polar organization identifier;
  • a locally generated activation label identifying the browser installation;
  • the Polar activation identifier when validating or deactivating an existing activation.

The licensing response contains license and activation metadata. ClickVeto stores the license key, license and activation identifiers, masked display key, status, expiry information and validation timestamps locally so that Pro status can be displayed and periodically revalidated.

Payment information: purchases are completed on Polar's checkout. ClickVeto does not receive or store credit-card numbers, bank details or other payment-instrument data.

5. Data not sent to ClickVeto

  • ClickVeto does not upload your browsing history to a ClickVeto server.
  • ClickVeto does not transmit the contents of downloaded files to a ClickVeto server.
  • ClickVeto does not sell personal data or browsing data.
  • ClickVeto does not use browsing data for advertising, cross-site profiling, credit scoring or lending decisions.

6. Permissions and broad website access

ClickVeto requests access to websites you visit because its protection must work across arbitrary sites. That access is used to inspect only the navigation, interaction and page signals required for the disclosed protection features. Broad host access does not mean that browsing data is sent to ClickVeto.

7. Manually blocked elements

If you use “ClickVeto: Block element” from the context menu, ClickVeto creates a local site-specific rule so the selected element can remain hidden on later visits. These rules remain in local extension storage until they are removed, reset or the extension is uninstalled.

8. Backups

If you create a ClickVeto backup, the backup is generated locally and downloaded as a file chosen by you. Pro license data, the local license installation identifier and temporary/session permissions are excluded from ClickVeto backups.

9. Retention and deletion

Local settings and logs remain in the browser until they are cleared through ClickVeto, Chrome extension storage is removed, or ClickVeto is uninstalled. License entitlement data remains locally until deactivation, reset or uninstall, subject to revalidation with the license provider. An installation-specific non-exportable cryptographic key in IndexedDB protects the integrity of the offline license cache. This key and the cache authentication code are not transmitted or included in ClickVeto backups. Existing licenses require one online confirmation after the security update; confirmed licenses retain up to seven days of offline grace.

Support messages submitted through GitHub are handled by GitHub and remain subject to GitHub's own retention and privacy practices.

10. Website hosting

The ClickVeto website is hosted using GitHub Pages. When you visit the website, GitHub may process technical request data such as IP address, browser information and server logs according to GitHub's own privacy policy. ClickVeto does not add its own analytics or advertising trackers to this privacy page.

The website stores your language preference locally. The privacy page may store its own language preference. These settings are not transmitted as analytics events.

11. Security

Licensing and filter-list requests use HTTPS. Protection processing and optional measurement remain local as described above. No software can guarantee absolute security.

12. Chrome Web Store Limited Use

ClickVeto's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

User data is used only to provide or improve ClickVeto's disclosed browser-protection and license-entitlement functionality. It is not sold, used for personalized advertising, used to determine creditworthiness, or transferred for purposes unrelated to ClickVeto's single purpose.

13. Third-party services

  • Polar: checkout and Pro license activation, validation and deactivation.
  • GitHub / GitHub Pages: website hosting and optional support through GitHub Issues.
  • Google Chrome / Chrome Web Store: browser platform and extension distribution. Chrome itself may process browser/extension information under Google's own terms and privacy policy.

13a. Filter-list downloads

ClickVeto may download protection filter lists over HTTPS from jsDelivr and GitHub. These requests do not send recorded browsing history or use sign-in credentials. Providers receive the ordinary technical connection data associated with serving a network request.

13b. Twitch Stream Shield (Pro, Beta)

When Twitch Stream Shield is enabled, ClickVeto processes the Twitch channel name, playlists and stream segments. Alternative playback can make additional requests to gql.twitch.tv, usher.ttvnw.net and the relevant Twitch stream/CDN addresses. Requests can reuse client, device, session and authorization headers already used by the Twitch page, together with playback tokens, and send them to Twitch. Headers and tokens are processed in page or worker memory for this function; they are not transmitted to ClickVeto or Polar and are not saved as license or profile information. Local protection events can contain channel names and feature status. Twitch also receives ordinary technical connection data. The feature can be disabled; website and channel exceptions prevent activation. Twitch processing is governed by its privacy policy.

14. Your choices and rights

You can disable ClickVeto, clear its local configuration, remove manually blocked elements, deactivate Pro, or uninstall the extension at any time. Depending on applicable law, you may also have rights relating to access, correction, deletion, restriction or objection regarding personal data processed by an external service. Requests concerning ClickVeto can be made through the support channel above; requests concerning Polar, GitHub or Google should also be directed to the relevant provider where appropriate.

15. Changes to this policy

This policy may be updated when ClickVeto's functionality, permissions or external service use changes. The “Last updated” date above identifies the current version.

Local page check and example demo

When you explicitly choose Check this page in ClickVeto, the existing local comfort detector reads supported distraction patterns on the main page and returns category counts to the extension popup. It does not hide elements, click controls, store those counts or transmit them. The interactive example demo modifies only its fictional article; it neither scans websites nor changes cookie consent. Presets change the selected settings only until you explicitly apply a Pro website profile. No new analytics or external service is added.

YouTube and Twitch video-ad protection (Pro, optional)

The optional YouTube shield processes already loaded player responses locally in memory and removes known ad entries. It may activate visible ad-skip controls. This module stores only its setting and aggregate local activity counters, not video titles, video IDs, URLs, listening history or account details. It sends no content to ClickVeto or an additional helper service. Normal YouTube/Google requests remain. The previously described optional Twitch shield and its Twitch requests remain unchanged; both features require Pro and explicit activation.

Nur Aktivierung, regelmäßige Prüfung und Deaktivierung einer Pro-Lizenz kommunizieren mit dem Lizenzdienst von Polar.

2. Alleiniger Zweck der Erweiterung

Der alleinige Zweck von ClickVeto ist der Schutz vor unerwünschten Browser-Aktionen und aufdringlichem Web-Verhalten, insbesondere unerwünschten Popups/Popundern, verdächtigen Redirects und Tab-Wechseln, riskanten Downloads, unerwünschten Werbe- und Netzwerkanfragen, täuschenden Overlays sowie damit verbundenen Browser-Nebenwirkungen.

3. Lokal verarbeitete Daten

Für diesen Schutz kann ClickVeto folgende Daten lokal im Browser verarbeiten:

  • Webprotokoll / Navigationskontext: Website-URLs, Hostnamen, Top-Level-Navigationen, Redirect-Ketten sowie Quell-/Zielbeziehungen, soweit dies für die Schutzentscheidung erforderlich ist.
  • Nutzeraktivität: Interaktionskontext wie Klicks, Tastatur-Auslösungen von Formularen und die Beziehung zwischen einer Nutzeraktion und den dadurch ausgelösten Browser-Aktionen.
  • Website-Inhalte und Seitenmetadaten: begrenzte DOM-Informationen, Links, Formularziele, iframe-Attribute, Werbe-/Overlay-Marker und vergleichbare Signale, die zur Erkennung störender Elemente oder zur Unterscheidung gewünschter und unerwünschter Aktionen nötig sind.
  • Schutzkonfiguration: Einstellungen, Allow-/Blocklisten, temporäre Freigaben, Website-Regeln, manuell blockierte Elemente, Schutzstufe und weitere Präferenzen.
  • Lokaler Schutzverlauf: Schutzereignisse, Zähler, Download-Entscheidungen, Website-Reputation/adaptive Signale sowie von ClickVeto bereitgestellte Diagnoseinformationen.

Diese Daten werden für Browserschutz und Fehlerdiagnose genutzt und – soweit nachfolgend nichts anderes genannt ist – im lokalen Chrome-Erweiterungsspeicher verarbeitet.

3a. Freiwillige lokale Messzähler

Freiwillige Messzähler sind standardmäßig ausgeschaltet. Nach deiner Aktivierung zählen sie Nutzungstage, Pro-Hinweise, Aufrufe der Pro-Seite, Kaufbutton-Klicks, geöffnete Checkout-Tabs und Lizenzaktivierungen. Sie enthalten keine URLs, Website-Namen, Lizenzschlüssel oder Nutzerkennungen und werden nicht übertragen. Deaktivieren löscht die Zählerdaten. Sie beschreiben nur diesen Browser; ein geöffneter Checkout belegt keinen Kauf. Hinweisbegrenzung und Ausblenden funktionieren unabhängig von der Messung.

3b. Persönliche Elementregeln

Persönliche Elementregeln enthalten Website-Domain, DOM-Auswahlregel, Regel-ID und Erstellungszeit. Sie werden lokal ohne Seitentexte oder vollständige URLs gespeichert und nicht übertragen.

3c. Player-Werkzeuge und Website-Profile

Player freiräumen blendet erkannte transparente Klickfallen vorübergehend aus. Die ursprünglichen Anzeigeeigenschaften bleiben nur im Arbeitsspeicher der Seite für Rückgängig erhalten; es entsteht keine gespeicherte Elementregel. Website zähmen speichert lokal die genaue Website-Domain, Aktivierungszustand und Erstellungszeit (höchstens 300 Profile), ohne vollständige URLs oder Seiteninhalte. Diese neuen Daten werden nicht übertragen oder synchronisiert. Website-Profile bleiben nach Neuladen erhalten, sind in exportierten Backups enthalten und können unter Meine Ausblendungen auch in Free entfernt werden. Bei ausgeschaltetem Schutz, einer Website-Ausnahme oder ohne Pro wirken die Profile nicht. Bestehende lokale Schutzprotokolle können weiterhin URLs enthalten, wie oben beschrieben.

3d. Vorläufige Fenster im Lockdown

Für die Prüfung eines zunächst leeren Fensters speichert ClickVeto vorübergehend im lokalen Chrome-Sitzungsspeicher die Quell-Domain, gegebenenfalls eine einmalig freigegebene Zieldomain, die Browser-Tab-IDs und den Erstellungszeitpunkt (höchstens 64 Einträge). Diese Daten werden nicht synchronisiert, übertragen oder in Einstellungs-Backups aufgenommen. Die Zuordnung wird nach Prüfung des ersten abgeschlossenen Ziels oder beim Schließen des Fensters entfernt; der Sitzungsspeicher wird beim Browserende geleert. Blockierungen können wie bisher Ziel-URL und Grund im lokalen Schutzprotokoll enthalten. Das Schließen eines fremden Ziels garantiert nicht, dass dessen erste Netzwerkanfrage verhindert wurde.

3e. Automatische kosmetische Werbefilterung (Pro)

Pro nutzt gebündelte kosmetische CSS-Regeln aus EasyList und EasyList Germany. Zur Laufzeit werden dafür keine Listen heruntergeladen; Seiteninhalte, URLs und Listentreffer-Zähler werden weder an die Listenautoren noch an ClickVeto übertragen. Der Aktivierungszustand und bis zu 300 genaue Website-Domains mit einer von dir gesetzten Ausblend-Pause werden lokal gespeichert und in Einstellungs-Backups aufgenommen. Styles und Listentreffer-Zähler der aktuellen Seite bleiben im Arbeitsspeicher der Seite. Eine Ausblend-Pause, ausgeschalteter Schutz, eine Website-Ausnahme oder fehlender Pro-Zugang entfernt die Styles dieser Funktion, ohne Seitenelemente zu löschen. Diese neuen Einstellungen bleiben lokal; bestehende Netzfilter-Downloads beschreibt Abschnitt 13a.

3f. Freiwilliger Komfortmodus und Cookie-Ablehnung (Pro)

Der Komfortmodus ist standardmäßig aus. Um unterstützte Newsletter-/Umfrage-Popups und stumme schwebende Autoplay-Videos zu erkennen, prüft ClickVeto DOM-Merkmale, begrenzte lokale Elementtexte, Formular-/Medienattribute und den Interaktionszustand auf der Seite. Diese Verarbeitung bleibt im Arbeitsspeicher der Seite; Inhalte und Trefferzahlen werden nicht übertragen oder als Historie gespeichert. Ursprüngliche Element- und Scroll-Eigenschaften bleiben vorübergehend im Seiten-Arbeitsspeicher für die Rücknahme. Globale Auswahl und bis zu 300 Komfortprofile für genaue Domains (Kategorieauswahl, Aktivierungszustand, Erstellungszeit, Pause-/Fortsetzungszustand und Eigentumsmarker eines gegebenenfalls erzeugten Zähmen-Profils) bleiben lokal und sind in Einstellungs-Backups enthalten. Entfernen stellt nur ein durch dieses Werkzeug erzeugtes Zähmen-Profil zurück, wenn dessen Erstellungsmarker noch passt. Cookie-Ablehnung benötigt eine eigene ausdrückliche Aktivierung, unabhängig von der Popup-Ausblendung, global oder pro Website; ein importiertes Einstellungs-Backup kann sie wiederherstellen. Sie betätigt sichtbare bekannte Ablehnen-/Nur-notwendige-Buttons in unterstützten Consentdialogen, höchstens fünf Versuche pro Seite. Sie klickt nicht auf Alle akzeptieren, verändert Consentcookies nicht selbst und versteckt unbekannte Cookie-Anfragen nicht. Websites oder deren Consent-Anbieter können die Ablehnung über ihre normale Verarbeitung und Netzwerkanfragen speichern oder empfangen; deren Datenschutzhinweise gelten. Ausschalten beendet künftige Aktionen, kann keine abgegebene Entscheidung zurücknehmen und belegt nicht, dass sämtliches Tracking beendet wurde.

3g. Freiwillige lokale Captcha-Hilfe (Pro, experimentell)

Dieser Abschnitt beschreibt den experimentellen lokalen Kandidaten 1.0.37, der noch nicht in der veröffentlichten Store-Version enthalten ist. Er gilt, wenn du diesen Kandidaten nutzt und die Hilfe ausdrücklich aktivierst.

Die Funktion ist zunächst ausgeschaltet und benötigt eine ausdrückliche Aktivierung für einzelne Website-Domains. Gebündelte OCR- und Bildklassifikationsmodelle verarbeiten Captcha-Bilder, begrenzte Aufgabentexte und relevante Formular-/Checkbox-Zustände lokal. Bilder, erkannte Texte und Vorhersagen bleiben im Arbeitsspeicher und werden weder an ClickVeto oder Modellautoren noch an einen kostenpflichtigen Lösungsdienst übertragen. Ist ein Bild auf der Seite nicht auslesbar, kann seine ursprüngliche Bildadresse auf der Website oder beim Captcha-Anbieter ohne Cookies und ohne Referrer abgerufen werden; dieser ursprüngliche Host erhält die üblichen Verbindungsdaten einschließlich IP-Adresse. Zur Laufzeit werden keine Solver-API, Modelldownloads oder externe KI-Berechnungen genutzt. Modelle und englische Zeichenerkennungsdaten sind im Paket enthalten. Aktivierungszustand und bis zu 300 genaue Website-Auswahlen werden lokal gespeichert und sind von Einstellungs-Backups ausgeschlossen. Pro Tab kann ein aktueller Ergebniscode mit Zeitstempel für diese Browsersitzung im Arbeitsspeicher bleiben, ohne Bilder oder vollständige URLs. Unterstützte Ergebnisse können ein leeres Captcha-Feld ausfüllen oder Bildkacheln auswählen; ClickVeto sendet das umgebende Formular nicht selbst ab. Ein sichtbares Bestätigungsfeld kann einmal pro Seite versucht werden, wodurch die normalen Prüfanfragen des Anbieters ausgelöst werden können. Serverprüfungen und Akzeptanz werden weder umgangen noch garantiert. Unsichere Aufgaben bleiben manuell. Ausschalten, ausgeschalteter Schutz, Website-Ausnahmen oder Pro-Verlust stoppen weitere Verarbeitung; laufende Ergebnisse werden vor dem Anwenden erneut geprüft. Ein vorübergehendes Hintergrunddokument betreibt lokale Worker und gibt Modelle nach Leerlauf frei. Kein kostenpflichtiger Dienst und kein zusätzliches Konto erforderlich.

4. Datenübertragung an Polar für Pro-Lizenzen

Für den Kernschutz sind weder ein ClickVeto-Konto noch ein ClickVeto-Server erforderlich. Wenn du ClickVeto Pro aktivierst, prüfst oder deaktivierst, kommuniziert ClickVeto direkt per HTTPS mit der Lizenz-API von Polar.

Dabei kann die Erweiterung insbesondere übermitteln:

  • den vom Nutzer eingegebenen Lizenzschlüssel;
  • die Polar-Organisationskennung von ClickVeto;
  • eine lokal erzeugte Aktivierungsbezeichnung für die Browserinstallation;
  • die von Polar vergebene Aktivierungs-ID bei späteren Prüfungen oder einer Deaktivierung.

Ein installationsbezogener, nicht exportierbarer Schlüssel in IndexedDB sichert den Offline-Lizenzcache gegen Datenänderungen. Schlüssel und Prüfcode werden nicht übertragen oder in ClickVeto-Backups gesichert. Nach dem Sicherheitsupdate ist einmal eine Online-Bestätigung nötig; bestätigte Lizenzen behalten bis zu sieben Tage Offline-Kulanz. Die Antwort des Lizenzdienstes enthält Lizenz- und Aktivierungsmetadaten. ClickVeto speichert den Lizenzschlüssel, Lizenz- und Aktivierungskennungen, die maskierte Schlüsselanzeige, Status, Ablaufangaben und Prüfzeitpunkte lokal, damit der Pro-Status angezeigt und regelmäßig erneut geprüft werden kann.

Zahlungsdaten: Der Kauf wird vollständig über den Checkout von Polar abgewickelt. ClickVeto erhält und speichert keine Kreditkartennummern, Bankdaten oder sonstige Zahlungsinstrumentdaten.

5. Daten, die ClickVeto nicht überträgt

  • ClickVeto lädt deinen Browserverlauf nicht auf einen ClickVeto-Server hoch.
  • ClickVeto überträgt den Inhalt heruntergeladener Dateien nicht an einen ClickVeto-Server.
  • ClickVeto verkauft keine personenbezogenen Daten oder Browserdaten.
  • ClickVeto nutzt Browserdaten nicht für Werbung, Cross-Site-Profilbildung, Bonitätsprüfung oder Kreditentscheidungen.

6. Berechtigungen und Zugriff auf Websites

ClickVeto benötigt Zugriff auf Websites, weil der Schutz auf beliebigen vom Nutzer besuchten Seiten funktionieren muss. Der Zugriff wird nur genutzt, um die für die beschriebenen Schutzfunktionen erforderlichen Navigations-, Interaktions- und Seitensignale auszuwerten. Eine breite Hostberechtigung bedeutet nicht, dass der Browserverlauf an ClickVeto übertragen wird.

7. Manuell blockierte Elemente

Wenn du über das Kontextmenü „ClickVeto: Element blockieren“ verwendest, legt ClickVeto eine lokale, websitespezifische Regel an, damit das ausgewählte Element bei späteren Besuchen ausgeblendet bleibt. Diese Regeln bleiben im lokalen Erweiterungsspeicher, bis sie entfernt/zurückgesetzt werden oder ClickVeto deinstalliert wird.

8. Backups

Ein ClickVeto-Backup wird lokal erzeugt und als Datei auf deinem Gerät gespeichert. Pro-Lizenzdaten, die lokale Lizenz-Installationskennung und temporäre bzw. sitzungsbezogene Freigaben werden nicht in ClickVeto-Backups exportiert.

9. Speicherdauer und Löschung

Lokale Einstellungen und Protokolle bleiben im Browser, bis sie über ClickVeto gelöscht/zurückgesetzt werden, der Erweiterungsspeicher entfernt wird oder ClickVeto deinstalliert wird. Lizenz-/Berechtigungsdaten bleiben bis zur Deaktivierung, zum Zurücksetzen oder zur Deinstallation lokal gespeichert und können regelmäßig beim Lizenzanbieter validiert werden.

Support-Nachrichten, die über GitHub eingereicht werden, werden von GitHub verarbeitet und unterliegen den dortigen Speicher- und Datenschutzregeln.

10. Hosting der Website

Die ClickVeto-Website wird über GitHub Pages bereitgestellt. Beim Aufruf kann GitHub technische Verbindungsdaten wie IP-Adresse, Browserinformationen und Server-Logs nach der eigenen Datenschutzerklärung verarbeiten. ClickVeto bindet auf dieser Datenschutzseite keine eigenen Analyse- oder Werbetracker ein.

Die Website speichert deine Sprachwahl lokal. Die Datenschutzerklärungsseite kann ihre eigene Sprachwahl speichern. Diese Einstellungen werden nicht als Analyseereignisse übertragen.

11. Sicherheit

Lizenzkommunikation und Filterlisten-Abrufe erfolgen per HTTPS. Schutzverarbeitung und freiwillige Messung bleiben wie oben beschrieben lokal. Keine Software kann absolute Sicherheit garantieren.

Nutzerdaten werden nur verwendet, um die offengelegten Browserschutz- und Lizenzberechtigungsfunktionen bereitzustellen bzw. zu verbessern.
